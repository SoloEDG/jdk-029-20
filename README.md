# 夜航练习室

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本机地址。麦克风需要本机地址或 HTTPS。

## 测试与构建

```sh
npm test        # 修订引擎、指标、旧盘解析等单元测试
npm run typecheck
npm run build
```

验证夹具（合成的「真跳紧贴倍频误判」音频与「只剩音高点」旧盘）由独立脚本生成：

```sh
python3 -I tools/make_fixtures.py
```

## 音高线八度修订

自动检测只作为原始轨迹，回顾时可对照原声做局部修订：

- **锁住真跳**：在音高图上点击确认是实际大跳（或实际音高）的点，锁点会固定该音并充当传播屏障。
- **移回原八度**：拖选疑似倍频折返的小段，整体上移或下移八度；同一声证据段内相邻的不确定音会重新判断。
- **证据边界**：修订只在连续有声证据内传播，无声缺口处明确标注「证据中断」，不会跨缺口改动；真实音程变化（音名切换）同样阻断传播。
- **争议处理**：同一段落里多个人工标记无法同时满足时，已确认的内容逐点保留，争议位置在图上标出并给出提示。
- **原轨 / 修订轨 / 原声共用同一歌曲时间轴**：原轨以虚线打底、修订轨以实线覆盖；撤销或清空修订后，命中率指标自动回到检测原值。
- **旧盘导入**：只剩音高点、没有音频的旧记录也能导入并修订，复听按钮会禁用并说明原因。

```sh
docker compose up --build
```
